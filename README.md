Automatic Digital Silencer Application

The Automatic Digital Silencer Application is an Android-based mobile application designed to help students stay focused during study hours by reducing smartphone distractions. The app allows users to set study schedules, and the device automatically switches to silent mode when a study session begins. Once the scheduled time ends, the phone returns to its normal sound profile without requiring any manual action.

The application runs in the background and continuously monitors the device time to manage sound settings automatically. It also includes an emergency bypass feature that allows calls from selected contacts, ensuring that important or urgent communication is not missed.

Developed using Android Studio with Java or Kotlin, the application uses lightweight storage methods such as Shared Preferences or SQLite to save user settings and schedules. By automating sound management during study sessions, the app helps improve concentration, productivity, and time management for students.
